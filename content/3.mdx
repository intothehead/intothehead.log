이 블로그는 다크 모드로 바꾼 것을 기억하려고 `localStorage`에 테마를 저장합니다. 브라우저에 값을 저장하는 방법은 이것 말고도 `sessionStorage`와 쿠키가 있는데, 셋은 **얼마나 오래 남는지, 서버로 가는지, 누가 읽을 수 있는지**가 다릅니다. 이 글에서는 세 가지를 비교하고 어떤 값을 어디에 둬야 하는지 정리합니다.

## 1. localStorage: 지울 때까지 남는다

`localStorage`에 저장한 값은 브라우저를 껐다 켜도 남아 있고, 같은 사이트의 모든 탭이 함께 씁니다. 보통 5MB 안팎까지 저장할 수 있고, 글자만 저장할 수 있어서 객체는 JSON 글자로 바꿔서 넣습니다.

```js
localStorage.setItem("theme", "dark");
localStorage.getItem("theme"); // "dark"

const settings = { fontSize: 16, theme: "dark" };
localStorage.setItem("settings", JSON.stringify(settings));

const saved = JSON.parse(localStorage.getItem("settings") ?? "{}");
```

`localStorage`는 브라우저에만 있어서 서버에서는 읽을 수 없습니다. 그래서 Next.js의 서버 컴포넌트에서는 쓸 수 없고, 클라이언트 컴포넌트나 브라우저에서 실행되는 스크립트에서 읽어야 합니다.

## 2. sessionStorage: 탭을 닫으면 사라진다

`sessionStorage`는 쓰는 방법이 `localStorage`와 같지만, 저장한 값이 **탭 하나에만** 남습니다. 새로고침해도 남아 있지만 탭을 닫으면 사라지고, 다른 탭에서는 보이지 않습니다.

```js
sessionStorage.setItem("draft", "작성 중인 글");
sessionStorage.getItem("draft"); // 탭을 닫기 전까지만 남는다
```

작성 중인 글을 잠깐 보관하거나, 탭을 연 동안 한 번만 보여 줄 안내를 기억할 때처럼 잠깐 쓰고 버릴 값에 어울립니다.

## 3. 쿠키: 요청마다 서버로 따라간다

쿠키는 앞의 둘과 성격이 다릅니다. 서버가 응답에 `Set-Cookie`를 실어 저장하게 하면, 그 뒤로 브라우저는 같은 사이트에 요청을 보낼 때마다 쿠키를 **자동으로 함께** 보냅니다. 그래서 로그인 상태를 유지하는 데 주로 씁니다.

```txt
Set-Cookie: sessionId=abc123; Max-Age=3600; Path=/; HttpOnly; Secure; SameSite=Lax
```

`Max-Age`는 몇 초 동안 남길지, `HttpOnly`는 자바스크립트(`document.cookie`)로 읽지 못하게 막기, `Secure`는 HTTPS에서만 보내기, `SameSite`는 다른 사이트에서 시작된 요청에 쿠키를 실을지 정하는 옵션입니다. 쿠키는 4KB 정도로 작고 요청마다 실려 가므로, 큰 데이터를 넣으면 모든 요청이 무거워집니다.

## 4. 한눈에 비교하고 고르기

```txt
localStorage     지울 때까지 남음 · 서버로 안 감 · 자바스크립트로 읽을 수 있음
sessionStorage   탭을 닫으면 사라짐 · 서버로 안 감 · 자바스크립트로 읽을 수 있음
쿠키             만료될 때까지 남음 · 요청마다 서버로 감 · HttpOnly면 못 읽음
```

로그인 토큰을 `localStorage`에 두면 편하지만, 페이지에 악성 스크립트가 끼어드는 XSS 공격을 당하면 그 스크립트가 토큰을 그대로 읽어 갈 수 있습니다. `HttpOnly` 쿠키는 자바스크립트로 읽을 수 없어서 토큰을 훔쳐 가기 어렵습니다. 대신 쿠키는 자동으로 실려 가므로, 다른 사이트가 내 로그인 정보로 요청을 보내게 만드는 CSRF 공격을 `SameSite` 같은 설정으로 막아야 합니다.

정리하면 테마나 언어처럼 보여져도 괜찮은 설정은 `localStorage`, 탭 하나에서만 잠깐 쓸 값은 `sessionStorage`, 로그인처럼 지켜야 하는 값은 `HttpOnly` 쿠키에 둡니다.

> 보여져도 괜찮은 값은 localStorage에, 지켜야 하는 값은 HttpOnly 쿠키에 둡니다.
