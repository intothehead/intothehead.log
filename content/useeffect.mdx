`useEffect`는 React를 배우면 가장 먼저 쓰는 Hook 중 하나지만, 가장 많이 잘못 쓰는 Hook이기도 합니다. `useEffect`는 렌더링이 끝난 뒤 React 바깥(타이머, 이벤트, 서버 요청)과 화면을 맞추는 도구입니다. 이 글에서는 언제 실행되는지, 무엇을 치워야 하는지, 언제는 쓰지 않아도 되는지 정리합니다.

## 1. 의존성 배열이 실행 시점을 정한다

```tsx
useEffect(() => {
  console.log("렌더링될 때마다");
});

useEffect(() => {
  console.log("처음 화면에 나타날 때 한 번");
}, []);

useEffect(() => {
  console.log("keyword가 바뀔 때마다");
}, [keyword]);
```

두 번째 인자인 배열에 적은 값이 바뀔 때만 다시 실행됩니다. 개발 모드의 Strict Mode에서는 일부러 한 번 실행했다가 치우고 다시 실행해서, 정리를 빠뜨린 곳이 없는지 확인해 줍니다. 처음 한 번만 실행되어야 하는 코드가 두 번 실행된다면 이 때문입니다.

## 2. 정리 함수: 쓰고 나면 치운다

`useEffect` 안에서 함수를 돌려주면, React는 다음 실행 전과 컴포넌트가 사라질 때 그 함수를 불러 줍니다. 타이머나 이벤트처럼 계속 살아 있는 것을 만들었다면 여기서 꼭 치워야 합니다.

```tsx
useEffect(() => {
  const id = setInterval(() => {
    setSeconds((prev) => prev + 1);
  }, 1000);

  return () => clearInterval(id);
}, []);
```

치우지 않으면 페이지를 떠나도 타이머가 계속 돌거나, 같은 이벤트가 여러 번 등록되어 한 번 눌렀는데 여러 번 실행되는 문제가 생깁니다.

## 3. 늦게 도착한 응답 막기

검색어가 바뀔 때마다 서버에 요청한다고 해 봅니다. 빠르게 입력하면 먼저 보낸 요청의 응답이 나중에 도착해서, 화면에 예전 검색 결과가 덮어써질 수 있습니다. 정리 함수로 이전 요청의 결과를 무시하게 만들면 해결됩니다.

```tsx
useEffect(() => {
  let ignore = false;

  fetch(`/api/search?q=${keyword}`)
    .then((res) => res.json())
    .then((data) => {
      if (!ignore) setResults(data);
    });

  return () => {
    ignore = true;
  };
}, [keyword]);
```

`keyword`가 바뀌면 이전 실행의 정리 함수가 `ignore`를 `true`로 바꿔서, 늦게 온 예전 응답은 화면에 반영되지 않습니다. 또 안에서 쓰는 값(`keyword`)을 의존성 배열에서 빠뜨리면 오래된 값을 기억하는 클로저 문제가 생기므로, ESLint의 `react-hooks/exhaustive-deps` 경고를 그냥 넘기지 않는 것이 좋습니다.

## 4. useEffect가 필요 없는 경우

이미 가진 state나 props로 계산할 수 있는 값은 `useEffect`로 따로 저장할 필요가 없습니다.

```tsx
// 필요 없는 effect: 렌더링이 한 번 더 일어난다
const [filtered, setFiltered] = useState<Post[]>([]);

useEffect(() => {
  setFiltered(posts.filter((post) => post.tags[0] === selectedTag));
}, [posts, selectedTag]);
```

```tsx
// 렌더링 중에 바로 계산하면 된다
const filtered = posts.filter((post) => post.tags[0] === selectedTag);
```

버튼을 눌렀을 때 할 일도 `useEffect`가 아니라 이벤트 핸들러에 바로 쓰면 됩니다. 이 블로그의 태그 필터도 `useEffect` 없이 렌더링 중에 목록을 거르고, 버튼의 `onClick`에서 state만 바꿉니다.

> useEffect는 React 바깥과 맞출 때 쓰는 도구이고, 계산은 렌더링 중에 하면 됩니다.
